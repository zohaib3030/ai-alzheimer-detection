# AI Alzheimer Detection 

A Python-based healthcare prototype that predicts Alzheimer’s disease risk from cognitive test data using machine learning and provides an interactive Streamlit app for easy use.

## 📌 Features
- Trains a machine learning model using Scikit-learn libraries
- Deploys the model with a Streamlit app for real-time predictions
- Includes responsible AI disclaimer for educational use

## Tech Stack
- Python
- Scikit-learn :contentReference[oaicite:6]{index=6}
- Streamlit
- Pandas, NumPy
